# Handbuch

Für die Bearbeiterin im Fachreferat. Technischer Aufbau und Start: [infrastruktur.md](infrastruktur.md).

## Grundregel

Das Werkzeug schlägt vor, Sie entscheiden. Kein Vorschlag wird ohne Ihre Bestätigung
übernommen, und keine Ausgabe ersetzt die fachliche und rechtliche Prüfung. Geben Sie keine
vertraulichen personenbezogenen Daten ein.

## Der Weg

```
Übersicht → Neue Richtlinie → Geführte Erhebung (Chat) → Abschnitte prüfen
         → Gesamtprüfung → Prüfvermerk → Richtlinientext → Word-Dateien

Übersicht → Vorhandenen Entwurf prüfen → Auskunft (ohne Vorgang, ohne Speichern)
```

Sie können jederzeit unterbrechen; gespeichert wird bei jedem Schritt.

## Übersicht

Ihre Entwürfe mit Zeitstempel, Finanzierungsquelle und einem Balken „Vollständigkeit".
Ein Klick auf den Titel öffnet die Abschnittsliste. „Neue Richtlinie erstellen" beginnt einen
neuen Vorgang.

## Neue Richtlinie

Eine Frage: **Bund/Land (GAK)** oder **Land**. Die Antwort steuert, welche Mustersätze und
welche Prüfungen später greifen — sie lässt sich später ändern, ändert dann aber die Prüflage.
Der Beihilfebezug wird unabhängig davon im Ablauf geprüft. „Chat-Erhebung starten" führt weiter.

## Geführte Erhebung (Chat)

Der Assistent stellt eine Frage je Stufe, Sie antworten frei in ganzen Sätzen — je konkreter,
desto belastbarer der Vorschlag. **Enter sendet, Umschalt + Enter macht einen Absatz.**

Die Antwort dauert **ein bis zwei Minuten**; das Feld bleibt so lange gesperrt. Danach erscheint
der Kasten **„Das habe ich verstanden"** mit einem Wert je Feld:

| Knopf | Wirkung |
|---|---|
| Vorschlag übernehmen | Werte werden in die Abschnitte geschrieben, die nächste Frage kommt |
| Korrigieren | Kasten schließt, Sie beschreiben im Chat, was falsch ist |
| Überspringen | Kasten schließt ohne Übernahme, nichts wird gespeichert |

Unter jedem Wert steht, **woher er kommt**. Lesen Sie das, bevor Sie übernehmen — die
Kennzeichnungen sind unten erklärt. Ist eine Fundstelle verlinkt, öffnet ein Klick das Dokument
an der richtigen Seite **neben** dem Vorschlag; „Schließen" klappt den Bereich wieder zu.

Steht „Zu … konnte aus Ihrer Angabe nichts abgeleitet werden", fehlt dem Werkzeug die
Information — antworten Sie genauer oder tragen Sie das Feld später im Formular ein.

## Vorhandenen Entwurf prüfen

Der zweite Weg, von der Übersicht aus. Sie laden eine fertige Datei hoch (PDF oder DOCX) und
bekommen in Sekunden eine Auskunft: welche der acht Bausteine sich finden lassen und zu
welchen Gliederungspunkten der Musterrichtlinie nichts im Entwurf steht.

Die Datei wird dabei **nicht gespeichert** und erscheint in keiner Entwurfsliste.

Die offenen Gliederungspunkte sind **Hinweise, keine Feststellungen**: verglichen werden
Wörter. Ein Punkt kann der Sache nach geregelt sein, ohne die Begriffe der Musterrichtlinie
zu benutzen.

## Abschnitte prüfen

Die Aufgabenliste zeigt alle elf Abschnitte mit Status. Reihenfolge beliebig. Ein Klick öffnet
das Formular des Abschnitts.

Im Formular: Pflichtfelder sind mit `*` gekennzeichnet, Hilfetexte stehen über dem Feld, und
manche Felder erscheinen erst, wenn eine vorherige Auswahl sie nötig macht. Blaue Hinweiskästen
sagen, welche Mustersätze später **automatisch** ergänzt werden — die müssen Sie nicht tippen.
„Speichern und zurück" schreibt die Angaben und setzt sie auf bestätigt.

## Gesamtprüfung

Listet fehlende Pflichtangaben und fachliche Prüfhinweise. Jeder Eintrag ist ein Link, der
direkt in das betroffene Feld springt.

## Prüfvermerk

Das zweite Arbeitsergebnis neben der Richtlinie: die begründungspflichtigen Abweichungen, die
in das Anschreiben an das MdFE gehören — etwa eine Bagatellgrenze unterhalb der Regelgrenze
oder eine Vollfinanzierung. Der Vermerk wächst mit jeder Prüfung mit; die Zahl offener Punkte
steht neben dem Knopf in der Abschnittsliste.

Zwei getrennte Schritte, mit Absicht:

1. **„Begründung speichern"** — das Fachreferat schreibt auf, warum abgewichen wird.
2. **„Begründung bestätigen"** — jemand anderes liest gegen und gibt frei. Ohne gespeicherte
   Begründung ist der Knopf gesperrt.

Ändern Sie später den auslösenden Wert, wird der Eintrag **gegenstandslos**: er bleibt als
Nachweis stehen, wird aber nicht mehr bearbeitet. Solange etwas offen oder unbestätigt ist,
ist die Richtlinie nicht einreichungsreif.

## Richtlinientext

Hier entsteht der ausformulierte Text aus den **bestätigten** Angaben. „Richtlinientext
erzeugen" dauert mehrere Minuten — ein Modellaufruf je Abschnitt; das Fenster kann offen
bleiben.

Je Abschnitt sehen Sie:

- **Befunde** über dem Text, wenn eine Prüfung etwas festgestellt hat.
- den **Text** selbst.
- **„Woher die Angaben stammen"** — aufklappbar, je Feld: aus Ihrer Chat-Angabe oder dem
  Formular, welcher Musterbaustein den Satzrahmen gab, welche Fundstelle, welche Prüfung.
- Abschnitte ohne bestätigte Angaben bleiben **leer**. Das ist gewollt: ein Abschnitt allein aus
  Musterbausteinen wäre die Musterrichtlinie, nicht Ihre.

Ändern Sie danach Angaben, meldet die Seite „Der Text ist älter als der Entwurf". Erzeugen Sie
ihn neu, bevor Sie ihn weitergeben.

Zwei getrennte Word-Dateien, mit Absicht — die Richtlinie wird veröffentlicht, das Anschreiben
geht ans Finanzministerium:

- **Richtlinie als Word** — nur der Text, ohne Befunde und Herkunftsangaben.
- **Prüfvermerk als Word** — die Abweichungen mit Begründung und Stand; offene Punkte werden
  als offen ausgewiesen.

## Kennzeichnungen lesen

**Status eines Abschnitts**

| Abzeichen | Bedeutung |
|---|---|
| Nicht begonnen | noch kein Wert erfasst |
| Durch Chat vorausgefüllt | Werte da, aber noch nicht im Formular bestätigt |
| Zu prüfen | enthält unbestätigte Werte |
| Unvollständig | ein Pflichtfeld fehlt |
| Vollständig | alle sichtbaren Pflichtfelder bestätigt |

**Herkunft eines Vorschlags** — der wichtigste Unterschied zu einem beliebigen Textgenerator

| Marke | Bedeutung |
|---|---|
| **durch Ihre Angabe gedeckt** | Der Wert steht so in Ihrer Eingabe; die tragende Stelle wird zitiert. |
| **aus dem Regelfall abgeleitet** | Ihre Angabe deckt den Wert nicht — besonders prüfen. |
| Ihre Angabe | Zitat aus Ihrem eigenen Text. |
| Musterbaustein | Satzrahmen aus der Musterrichtlinie. |
| Dazu gefunden | Eine echte, zeichengenau geprüfte Stelle zum Thema — **kein Nachweis für diesen Wert.** |
| Vorbild | So ist es in einer früheren Richtlinie geregelt: **bisherige Praxis, keine Rechtsgrundlage.** Fachlich bestätigen. |
| Konfidenz | Selbsteinschätzung des Modells. Ein Anhaltspunkt, kein Beleg. |

**Stand einer Vermerkbegründung**: Begründung fehlt · begründet, nicht bestätigt · bestätigt ·
gegenstandslos.

## Wenn etwas klemmt

| Meldung | Was tun |
|---|---|
| „Die fachliche Zuarbeit ist derzeit nicht erreichbar" | Der Vorschlagsdienst läuft nicht. Sie können alle Angaben im Formular selbst eintragen; es wird bewusst nichts erfunden. |
| „Der Entwurf wurde zwischenzeitlich geändert" | Der Entwurf ist in einem anderen Fenster verändert worden. Seite neu laden, Eingabe wiederholen. |
| Der Belegbereich bleibt leer | Der eingebettete Betrachter zeigt nichts — der Link „in einem neuen Tab öffnen" darunter geht trotzdem. |
| „Der Text ist älter als der Entwurf" | Richtlinientext neu erzeugen. Der Word-Export ist bis dahin gesperrt. |
| Ein Abschnitt bleibt im Text leer | Für ihn ist noch keine Angabe bestätigt. Formular ausfüllen, dann neu erzeugen. |
